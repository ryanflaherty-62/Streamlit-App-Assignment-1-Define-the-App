# Real Estate Investment Analyzer

## Student Name
Ryan Flaherty

## App Description
This app will help users analyze real estate investments by evaluating returns, risk, and key financial metrics. It is designed to simplify the process of understanding whether a property is a good investment by breaking down complex calculations into clear, easy-to-read results. The goal is to make real estate analysis more accessible and intuitive for users with varying levels of financial knowledge.

## Intended Users
This app is intended for students, beginner investors, and individuals interested in understanding real estate investment performance. It is especially useful for those who are new to real estate or finance and want a straightforward way to evaluate potential investments without needing advanced technical skills or financial modeling experience.

## Planned Features
- Calculate expected return and risk of investments
- Compare multiple real estate properties
- Display results using simple charts and visuals
